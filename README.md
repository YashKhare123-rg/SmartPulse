# SmartPulse

Real-Time Predictive Analytics and Data Engineering Platform.

## Status

Project initialization.

## Technology Stack

- Java
- Spring Boot
- Apache Spark
- Apache Kafka
- Microsoft Azure
- MySQL
- Machine Learning
- React
- Power BI

## Project Goal

SmartPulse is an end-to-end platform for collecting, processing, analyzing, and predicting industrial machine behavior using large-scale data engineering and machine learning.
